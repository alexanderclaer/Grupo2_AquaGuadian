# Grupo2_AquaGuadian
La propuesta AquaGuardian aborda una necesidad pertinente: centralizar información sobre especies y hábitats marinos para facilitar el aprendizaje y promover la conciencia ambiental. El objetivo y las funcionalidades están definidos con claridad, incluyendo el registro de usuarios, la exploración del parque virtual, la consulta de especies y el acceso a noticias y eventos.

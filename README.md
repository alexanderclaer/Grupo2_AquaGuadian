# Grupo2_AquaGuardian

## Descripción y objetivo
AquaGuardian es una plataforma web educativa de conservación marina. Su objetivo es concientizar e informar sobre la importancia y conservación de la vida marina.

## Problema que busca resolver
La información sobre especies y hábitats marinos está dispersa. AquaGuardian la centraliza para facilitar el aprendizaje y promover la conciencia ambiental.

## Funcionalidades
- Registro de usuarios
- Exploración del parque virtual
- Consulta de especies
- Acceso a noticias y eventos
